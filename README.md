# 💸 Responsive Pricing Panel

A responsive and stylish pricing table built using HTML and CSS. The design showcases three pricing tiers — **Personal**, **Small Team**, and **Enterprise** — each with feature lists, pricing, and call-to-action buttons.

## 🚀 Features

- 📱 Fully responsive layout using Flexbox and media queries
- ✨ Clean UI with hover and focus effects
- ⭐ Highlights the featured pricing plan
- 🧩 Perfect for SaaS or landing page projects

---

## 🔧 Technologies Used

- HTML5
- CSS3 (with Flexbox)
- Google Fonts – *Open Sans*
